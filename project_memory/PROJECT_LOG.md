# سجل مشروع الحضور

يسجل هذا الملف حقائق وقرارات قابلة للمراجعة. أي تصحيح يضاف كسطر جديد ولا يمحو القرار السابق.

## الحالة الحالية

- النسخة: `V1.0` — Attendance foundation with local update history.
- النطاق: رفع ودمج ومتابعة الحضور، مع إثراء اختياري بالموظف والوردية والإجازة عبر رفع أربع ملفات معًا (`/api/upload_multi` وواجهة مخصصة في `dashboard.html`).
- مصدر الاختبار: بيانات صناعية من `HR_FACTORY_SYNTHETIC_DATASET_V1.zip`؛ لا تمثل بيانات شركة أو موظفين حقيقيين.
- جودة المعلومة: هيكل شيت الحضور واضح؛ سياسة بيانات الإنتاج اليومية لم تصل بعد.
- مسار التشغيل: ويندوز، `START.bat`، متصفح محلي، دون إنترنت بعد التثبيت.
